# PR Title Fix Required

## Current PR Title
```
Amplitude footer click event
```

## Required Format
According to `CONTRIBUTING.md`, PR titles must follow [conventional commit standards](https://www.conventionalcommits.org/en/v1.0.0/).

## Suggested PR Title
```
feat(guides): track powered by amplitude footer clicks
```

Or alternatively:
```
feat: add click tracking for guides footer
```

## How to Update

Update the PR title on GitHub to one of the suggested formats above.

The format is: `<type>(<scope>): <description>`

- **Type**: `feat` (new feature)
- **Scope**: `guides` (optional, but recommended)
- **Description**: brief description in lowercase

This will fix the "Check PR for semantic title" CI failure.
